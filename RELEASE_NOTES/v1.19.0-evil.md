# v1.19.0-evil

For Minecraft 26.2. Fabric is supported.

Built from upstream cabaletta/baritone tag [v1.19.0](https://github.com/cabaletta/baritone/releases/tag/v1.19.0) (commit `9fadf7cf9529`).

## Evil fork additions

- Modid renamed from `baritone` to `baritone-evil` so it can coexist with upstream baritone in the Fabric mod registry without a silent dedup conflict.
- `breaks: baritone` block — Fabric refuses to start with a clear actionable error if upstream `baritone-*.jar` is also present.
- Removed ProGuard rules, no need for fabric API jar anymore.

## Install

Drop `baritone-standalone-fabric-1.19.0-evil.jar` into your `mods/` folder. If you already have an upstream `baritone-*-fabric-*.jar` in there, Fabric will tell you to remove one of the two on next launch.
