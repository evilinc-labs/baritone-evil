# v1.15.0-evil

For Minecraft 1.21.6, 1.21.7 and 1.21.8. Fabric is supported.

Built from upstream cabaletta/baritone tag [v1.15.0](https://github.com/cabaletta/baritone/releases/tag/v1.15.0) (commit `612a8a6dc31e`).

## Evil fork additions

- Modid renamed from `baritone` to `baritone-evil` so it can coexist with upstream baritone in the Fabric mod registry without a silent dedup conflict.
- `breaks: baritone` block — Fabric refuses to start with a clear actionable error if upstream `baritone-*.jar` is also present.
- KISS: Removed ProGuard rules, no need for fabric API jar anymore.

## Install

Drop `baritone-standalone-fabric-1.15.0-evil.jar` into your `mods/` folder. If you already have an upstream `baritone-*-fabric-*.jar` in there, Fabric will tell you to remove one of the two on next launch.
