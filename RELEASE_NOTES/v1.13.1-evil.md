# v1.13.1-evil

For Minecraft 1.21.4. Fabric is supported.

Built from upstream cabaletta/baritone tag [v1.13.1](https://github.com/cabaletta/baritone/releases/tag/v1.13.1) (commit `a99e25eb8dc2`).

## Evil fork additions

- Modid renamed from `baritone` to `baritone-evil` so it can coexist with upstream baritone in the Fabric mod registry without a silent dedup conflict.
- `breaks: baritone` block — Fabric refuses to start with a clear actionable error if upstream `baritone-*.jar` is also present.
- KISS: Removed ProGuard rules, no need for fabric API jar anymore.

## Install

Drop `baritone-standalone-fabric-1.13.1-evil.jar` into your `mods/` folder. If you already have an upstream `baritone-*-fabric-*.jar` in there, Fabric will tell you to remove one of the two on next launch.
